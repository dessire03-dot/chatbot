🚀 Publicar en GitHub Pages — Paso a paso
Tendrás un link permanente y gratuito como: tunombre.github.io/clinica
1
Ve a github.com y crea una cuenta gratuita si no tienes una.
2
Haz clic en "New repository" (botón verde). Nómbralo clinica y márcalo como Public. Activa "Add a README file".
3
Dentro del repositorio, haz clic en "Add file → Upload files" y sube el archivo index.html que descargaste. Haz clic en "Commit changes".
4
Ve a Settings → Pages. En "Branch" selecciona main y haz clic en Save.
5
¡Listo! En 1-2 minutos tu chatbot estará en: https://tunombre.github.io/clinica
Importante: Para que el chatbot funcione necesitas una API key de Anthropic. Ve a console.anthropic.com, crea una cuenta, genera una API key y reemplaza TU_API_KEY_AQUI en el archivo HTML.
¿Dónde pongo mi API key en el archivo?
// Busca esta línea en el archivo index.html: const API_KEY = "TU_API_KEY_AQUI"; // Reemplázala con tu key real, ejemplo: const API_KEY = "sk-ant-api03-xxxxx...";
